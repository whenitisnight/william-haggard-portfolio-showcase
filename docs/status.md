# Current scope

Source checkpoint: November 4, 2026. Portfolio record published November 19, 2026.

The portfolio supports a connected project map, an alternative index, project stories, draft previews, ordered media galleries, project duplication and reversible archiving. Owner-only controls manage profile details and imports from a curated tracker export. Stable identifiers retain project URLs across reimports; existing stories and media are preserved.

Navigation offers keyboard controls, reduced-motion support and an ambient-motion pause. Search, filters, pages and view selection are represented in the URL. The content model supports bounded pagination and concurrent-edit conflict detection.

The existing README describes a private review deployment. Source synchronization does not publish the site, change DNS or configure a personal domain. Live database contents and uploaded images are external data requiring their own backup. No fresh production or physical-device acceptance is claimed here.
