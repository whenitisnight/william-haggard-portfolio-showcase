# A portfolio that can grow with the work

I wanted a cinematic project map with an equally usable searchable index, while making additions and removals manageable through an owner-only content studio.

The implemented site combines a connected project map, individual project stories, media galleries and draft/published/archived content. The studio supports content editing, import from a curated tracker selection and persistent media storage. This repository explains the system; application source stays private.
