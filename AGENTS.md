# Public portfolio guidance

This is an independent public documentation repository. Keep its history separate from private implementation. Publish only deliberately reviewed prose and media; never copy private source, branches, credentials, account data, machine paths, conversation links or internal logs.

Keep the README concise and link focused status, architecture and decision records. Write from the owner's perspective, stating actual mechanisms, evidence, failures, tradeoffs and limits. Identify AI assistance honestly. Do not invent hands-on testing, historical milestones, customer success or completion claims. Preserve the original date/scope of reused verification. Inspect new screenshots before publishing.

Group meaningful changes into cohesive entries. Verify links and content before publication, then verify the remote commit. Routine additive documentation can use main. Do not alter visibility, rewrite history, merge implementation PRs or deploy applications without authorization.
